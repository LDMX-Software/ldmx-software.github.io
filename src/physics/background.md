# Physics Background

There are many resources available giving background on the physics motivation
for the purpose and design of LDMX. This page is an attempt to manually collect
them in an easily-accessible location.

Another page that collects resources like these is the
[LDMX Publications and Presentations](https://confluence.slac.stanford.edu/spaces/MME/pages/211795743/Publications+and+Presentations) page on confluence which is public.

## Print
- [Jeremy Man's "One-Pager" (actually 5-page) description from 2017](https://www.epj-conferences.org/articles/epjconf/pdf/2017/11/epjconf_admpp2017_01020.pdf): old (missing Trigger Scintilator for example) but helpful and short read
- [LDMX Contribution to Snowmass 2021](https://inspirehep.net/literature/2053415): medium length (26 pages)
- [LDMX Design Report from 2025](https://arxiv.org/abs/2508.11833): large length (291 pages) but a lots more detail
